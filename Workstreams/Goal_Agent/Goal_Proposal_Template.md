# GOAL-PROP-YYYYMMDD: short topic

> **Goal proposal.** A candidate goal. Nothing is done until the owner approves it (APPROVE). This file is public (PUB-D-03).

## Source lineage (required, primary sources only)

| Field | Value |
|-------|-------|
| **Source type** | POSIWID analysis · Owner's request · Issue list |
| **Citation** | INDEX route and file name; or issue ID; or the date of the request and the request in a sentence |
| **Extract used** | Gap number, expectation, issue statement, or the outcome asked for |

*A proposal without one of these three source types isn't valid.*

## Proposal

| Field | Value |
|-------|-------|
| **Proposed goal** | One sentence: the measurable outcome if this succeeds |
| **Why now** | The trigger, the cost of waiting, or the opportunity |
| **Success looks like** | What the owner could show when it's done |
| **POSIWID anchor (draft)** | The analysis it comes from, or "needs an analysis" |
| **Draft measure** | Metric · baseline · target · by when |
| **Out of scope and risks** | What this goal won't do, and what could go wrong |

**APPROVE:** ☐ Approve ☐ Revise ☐ Reject, on YYYY-MM-DD

*Revise or Reject: stop. Write nothing else until the owner approves.*

|-------|-------|
